# Homework
Homework for the PNC Bootcamp


When homework is required to be turned in, create a folder in your local repository using the date the homework was assigned as the name of the folder. Please use "yyyy-mm-dd" as the format so that it sorts in chronological order.

Place your finished homework in that folder, create a commit, and push the branch to the remote repository, and that will submit your homework.

When homework is assigned, it will be due by the beginning of the next class. Homework assigned on a Friday afternoon will be due by 9:00 Monday morning.

NOTE: Once the hybrid portion of the bootcamp starts, if the next workday after homework assignment will be an in-office day, homework will still be due as if that was an in-class day. For example, if homework is assigned on Friday afternoon, and you are in the office Monday and Tuesday, the homework is still due by 9:00 Monday.
